# Counter-War Brand Assets

The `CW` shield and `COUNTER-WAR` wordmark are original vector artwork created
for this project. All lettering is custom SVG path geometry; no font file,
third-party logo, stock artwork, or watermark is used.

Palette:

- Charcoal: `#15191D`
- Steel/off-white: `#E7E2D7`
- Muted steel: `#59616A`
- Amber accent: `#C98A3D`

`cw_mark.svg` is the editable icon master. `cw_mark_small.svg` is its simplified
optical master for 16, 32, and 48 pixel rendering. `counter_war_logo.svg` is
the editable full-logo master. Raster and Windows icon derivatives are
generated from these masters.
