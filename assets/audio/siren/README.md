# Stage 07 — Harbor Alarm Siren Audio

Add a legally usable emergency / industrial siren audio file to this folder.

### Supported Formats & File Names:
- `alarm_siren.wav`
- `alarm_siren.ogg`
- `alarm_siren.mp3`

### Procedural Fallback:
If no audio file is placed in this folder, Stage 07 automatically synthesizes an emergency military klaxon siren in memory (dual harmonic frequency sweep with continuous `LOOP_FORWARD`).

### Recommended Free & Legal Audio Sources (CC0 / Public Domain):
1. **Freesound.org**
   - Search: `industrial siren` or `emergency siren`
   - Filter by: `License: Creative Commons 0 (CC0)`
2. **OpenGameArt.org**
   - Search: `siren` or `alarm`
   - Filter by: `Art Type: Sound Effect` + `CC0 (Public Domain)`
3. **Kenney.nl**
   - Package: `Kenney Game Audio` (CC0 1.0 Universal)
